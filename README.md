# 食灵·列传 Shiling Legends

山海经题材的单机网页自走棋 demo。玩家在每场战斗前用金币招募伙伴、武器、技能和山海胚胎，安排六格阵型；进入战斗后双方自动交战。

当前版本的目标是验证“招募构筑 + 六格布阵 + 自动对抗 + 数值养成”的核心乐趣。

```bash
npm test
npm run dev
```

打开 http://127.0.0.1:4195 即可试玩。

# 食灵 · 列传：山海牌局

《列传》的独立卡牌玩法原型。复用山海探索、吞噬器官与血脉传承的设计，使用独立的小局规则；尚未迁入原文字版内容引擎或血脉存档。

运行：`node serve.mjs`，打开 http://127.0.0.1:4195 。无需安装依赖。
测试：`npm test`。

## 玩法

- 选择初生器官，完成六次三选一探索，最终挑战穷奇。
- 点击地点前往，也可把地点牌拖到左侧灵狐。
- 探索或狩猎取得器官；地图中点击行囊装配，点击身体槽卸下。也可拖入身体区域。
- 身体最多三枚器官：夜瞳潜行、鳞甲反击、狐尾伙伴；裂爪、疾足、火囊改变构筑。
- 每回合灵力有限，出牌后点结束回合；敌人意图提前公开。
- 救治灵兔获得协力伙伴。喷火会毁坏普通战利品。
- 胜利可选择一枚已装备器官传承，再开启下一世。

本机 localStorage 自动保存，每一步立即写入；同源标签页接收更新（同时操作以最后写入为准）。无账户、跨设备同步或服务端。独立 `shiling.cards.v1` 存档不影响原游戏。存档异常会回到初生界面，写入失败会显示提醒。牌组与历史记录有上限。

这是可操作性验证，六组固定遭遇轮换位置；还没有动态生态、程序化地图、跨局遗迹或长期内容。插画为原创 SVG，未用图片 API。战斗数值仍需试玩调整。

## 当前默认入口：山海招募自走棋

index.html 已回到 expedition.mjs：每回合用金币购买伙伴、刷新商店、升级训练，最多 6 个伙伴上阵。战前在后排/前排 × 上中下六格里排阵，进入战斗后双方自由自动对战，不需要手动点技能、选目标或结束回合。

伙伴重新显示战斗定位：玄龟是慢速近战守卫，狰兽是高速近战刺客，毕方是蓄力远程术士。商店、候场区和阵位都会显示近战/远程/速度标签，方便做购买和站位判断。

2026-09-14 备战界面改为参考自走棋商店的竖屏棋盘布局：上方招募区固定 3 张混合商店卡，随机出现伙伴、武器、技能；中间布阵区用 3×2 站位展示六个伙伴；底部手牌区放候场伙伴和装备，并固定出战按钮。拖招募卡到手牌区等同购买，拖伙伴/装备到阵位完成上阵或装备，拖手牌或阵位伙伴到招募区出售。金币结算随战斗回合递增，每场结束获得 3 点商店经验；商店最高 6 星，升级消耗随星级递增：4 / 6 / 8 / 10 / 12 经验。经验足够时会自动升级商店，经验不足时可用金币补足差额主动升级。不同商店星级按不同概率刷新 1–6 星伙伴、武器和技能；三张同名伙伴仍会合成更高战斗星级，商店星级决定牌池，伙伴 ★ 决定上阵战力。

2026-09-14 独特玩法加入“山海胚胎”：商店会随机出现可孵化胚胎，购买后不会立刻变成伙伴，而是在下一战备战时自动孵化出本局唯一异兽。生成异兽会继承龟 / 鸟 / 狼三类战斗定位，同时随机获得野兽 / 羽族 / 灵族羁绊、元素属性、专属名字、色相外观和血脉变异。当前血脉包含角突（增伤）、鳞甲（生命）、翼足（冷却）、火囊（开战强化普攻）和月纹（开战护盾）；这些词条会真实进入自动战斗数值，允许同一套自走棋框架里出现不可完全复刻的阵容。
